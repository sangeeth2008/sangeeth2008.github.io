My Engineering Journey

A futuristic path connecting foundational mechatronics principles, hands-on microcontroller firmware, networked IoT systems, and edge intelligence.

MILESTONE 01 // FOUNDATIONS

B.Tech Mechatronics Engineering

Building rigorous fundamentals in mechanical kinematics, circuit theory, CAD modeling, and actuator systems at Jyothi Engineering College, Kerala. Bridging hardware design with mathematical modeling.

MILESTONE 02 // EMBEDDED CONTROL

C/C++ Firmware & Microcontrollers

Developing deterministic, non-blocking Finite State Machine (FSM) firmware on ESP32, Arduino, and microcontrollers. Managing hardware timer interrupts, dual-core tasks in FreeRTOS, and peripheral bus protocols (I2C, SPI, UART).

MILESTONE 03 // CONNECTIVITY

Internet of Things (IoT) Systems

Architecting bidirectional telemetry systems with MQTT brokers, Blynk IoT dashboards, and wireless MJPEG camera streaming for real-time remote environmental sensing and actuator telemetry.

MILESTONE 04 // MACHINE PERCEPTION

Edge AI & TinyML Deployment

Training and quantizing lightweight convolutional neural network models using Edge Impulse and TensorFlow Lite Micro. Running real-time visual classification and anomaly detection on low-power microcontrollers.

MILESTONE 05 // SYSTEM RESILIENCE

Hardware Failsafes & Cybersecurity

Engineering safety watchdogs, brownout recovery routines, tilt protection cutoffs, and authenticated telemetry communication channels to protect cyber-physical systems against runtime anomalies.

MILESTONE 06 // FUTURE GOALS

Continuous mission: Designing fully autonomous, self-navigating industrial mobile robots and intelligent mechatronic machines that enhance human capabilities and solve real-world problems.
